## 自动审计

运行：

```bash
npm run audit:standard-listening
```

该命令会检查标准版 Set 13–20 的：

- 五个 Part 是否齐全；
- 每个 Part 是否包含 5 题；
- 选择题答案范围及选项数量；
- Part 1 图片是否存在；
- 40 个音频文件是否存在且非空。
