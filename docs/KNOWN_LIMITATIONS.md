# 已知限制与技术债

更新时间：2026-09-21

## 内容与题库

- 青少版 12 套完成度较高，但正式发布前仍需第二人逐套抽查；
- 标准版 8 套阅读写作和听力均可练；口语视觉材料已定位，但尚未结构化接入；
- Part 5 有 39 套专项题库，其中部分不是已核验的整套原卷，界面必须继续与“官方整卷”分区；
- 题目、图片和音频的公开与商业使用权尚未完成逐项书面确认。

## 技术

- 用户进度仅存于浏览器 `localStorage`，不支持账号、换设备同步或可靠恢复；
- 仓库约 3GB，前端公开资源约 886MB，音频约 855MB；正式版需迁移对象存储/CDN；
- 当前生产构建通过，但主 JavaScript 包约 2.35MB（gzip 约 705KB），需要路由和题库分包；
- 当前 ESLint 基线为 62 个错误、5 个警告，主要是未使用变量、空代码块及 React hooks 规则；
- 尚无自动化端到端测试；
- 尚无服务端、数据库、账号权限、后台、监控和告警。

## 产品与运营

- PET/FCE 尚未按 KET 基准完成；
- CAE/CPE 仍有历史展示/数据代码，正式产品应从可见路线和级别选择中移除；
- 口语目前为参考答案和自评，不是官方评分或自动评分；
- 尚无隐私政策、用户协议、未成年人流程、客服、支付与退款能力；
- 中国大陆上线主体、域名、备案、前置审批和版权授权尚未确认。

## 推荐清理顺序

1. 版权与授权台账；
2. 修复 ESLint 基线并加入 CI；
3. 隐藏 CAE/CPE，冻结 KET/PET/FCE 产品范围；
4. 统一跨级别题库 schema；
5. PET 最小端到端试做；
6. 账号、后端、对象存储和跨设备同步设计；
7. 中国上线合规和内测。
