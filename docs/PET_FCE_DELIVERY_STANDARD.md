# PET / FCE 开发与验收标准

## 1. 总原则

PET 和 FCE 复用 KET 的产品闭环与组件，但不复制 KET 的考试结构。每个级别的 Paper、Part、题量、时长、作答规则和评分必须以当前 Cambridge 官方手册/样题为准，并记录查证日期。

完成顺序：PET 全部通过验收后，再进入 FCE。不要同时铺开两个级别造成大量半成品。

## 2. 统一的数据模型

每道题至少包含：

- `level`：PET 或 FCE；
- `examId`、系列、册号、Test；
- Paper 与 Part；
- 题型模板；
- 题干、选项、正确答案和可接受答案；
- 解析或参考回答；
- 图片/音频及替代文本；
- 源文件、页码、答案页和核对状态；
- 版权/授权状态；
- 专项标签（主题、技能、难度）。

专项练习和真题模考只引用这份数据，不分别维护两套答案。

## 3. 交互标准

所有级别保持以下一致体验：

- 清晰显示当前级别、Paper、Part 和题目进度；
- 正式模考按 Paper/Part 顺序进行；
- 可暂停计时，从刷新后恢复；
- 未完成题提示，但不能意外丢失答案；
- 交卷后显示总分和分 Part 结果；
- 可以查看错误题、正确答案和解释；
- “重做错题”只显示错误题，不混入已经做对的题；
- 重新选择/更正匹配题不会被“已使用”状态锁死；
- 阅读文本和选项都支持拖选查词；
- 拼写错误进入复习；
- 写作草稿自动保存，口语参考答案逐题对应；
- 桌面和窄屏均可完成核心流程。

## 4. 内容录入流程

每套题依次经过：

1. 资料登记：文件、版本、页码、音频和答案；
2. 权利状态登记：是否允许数字化、公开和商业使用；
3. 结构化录入；
4. 录入者逐题对照原件；
5. 第二人复核题干、选项、答案、图片和音频；
6. 接入专项练习；
7. 接入整套模考；
8. 自动审计；
9. 人工全流程测试；
10. 标记为 Ready。

只完成步骤 3 不等于“完成一套题”。

## 6. 上线门槛

一个级别只有满足下列条件才可出现在正式级别选择器中：

- 官方结构已确认；
- 所有标记 Ready 的套题能够完整交卷；
- 没有缺失音频、图片、答案或参考材料；
- 专项与模考答案一致；
- 查词覆盖审计没有“未收录”阻断项；
- 错题、拼写复习、生词库和打印在该级别正常；
- 自动检查和生产构建通过；
- 版权和公开范围已确认；
- 已有明确的已知限制说明。

## 7. 明确不做

- 不开发 CAE/CPE；
- 不在没有人类复核的情况下批量生成“官方答案”；
- 不为了赶进度把扫描 PDF 直接嵌入当作互动题；
- 不为 PET/FCE 另建孤立网站；
- 不重复上传同一媒体文件。
