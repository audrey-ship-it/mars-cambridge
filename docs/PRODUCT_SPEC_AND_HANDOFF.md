# Mars Cambridge 产品与功能完整说明

文档版本：1.0  
基准产品：A2 KET  
后续范围：B1 PET、B2 FCE  
不做范围：C1 CAE、C2 CPE

## 1. 产品定位

Mars Cambridge 是一个面向中国剑桥英语学习者的学习、专项训练与整套模考平台。核心价值不是简单展示题目，而是把“学习计划—专项训练—模考—反馈—错题/生词复习—再次测试”连成闭环。

主要用户：

- 正在准备 KET、PET、FCE 的学生；
- 需要查看学习进度和薄弱项的家长；
- 组织题库、检查内容和跟踪完成度的教研/运营人员。

当前 KET 版本是产品原型和 PET/FCE 的实现基准。它已经覆盖主要前端互动，但尚未具备正式商业网站所需的账号、服务端、后台、支付和生产运维能力。

## 2. 信息架构

网站主导航由以下区域组成：

1. 我的学习：今日任务、周计划、连续学习、模块进度和最近结果；
2. 单词：分主题词表、必默词、阅读高频词、不规则变化、复习队列；
3. 语法：按类别和单元学习、做题、反馈和语法错题；
4. 听力：按 Part 的专项训练和整套听力模考；
5. 阅读：按 Part 的专项训练、文本标记和查词；
6. 写作：题目、草稿、参考答案和写作提示；
7. 口语：题目、图片材料、逐题参考答案和自评；
8. 模考：按一套真题组织听力、阅读写作和口语；
9. 我的生词库：查词收藏、删除、复习和打印；
10. 错题中心：查看错题、正确答案、解析和只重做错题。

## 3. 已实现功能

### 3.1 学习中心

- 显示今日任务、周学习计划、连续学习天数和各模块进度；
- 汇总词汇、语法、听力、阅读、写作、口语与模考记录；
- 支持调整计划和从任务直接进入练习；
- 当前数据只保存在本机浏览器，清除浏览器数据或更换设备后不会自动恢复。

### 3.2 词汇与拼写

- KET 分主题词汇、必默词、阅读高频词和词形变化；
- 英式发音播放、音标、中文释义、英文解释和拼写训练；
- 答错进入复习队列，可重复练习；
- 拼写错误进入错题/复习体系；
- 词汇掌握状态和最近结果进入学习中心。

### 3.3 页面查词与生词库

- 阅读内容中拖选单词、短语或专有名词，弹出中文释义；
- 单击普通正文不会触发，避免影响阅读体验；
- 只选到 `ound` 等残缺内容时自动扩展到完整单词 `round`；
- 两个及以上单词仍通过拖选；按钮、输入框、播放器等互动区域不会误触；
- 覆盖词形还原、不规则过去式、常见短语、地名与国家缩写；
- 可加入/移出生词库；
- 生词库提供中英文版和默写版打印；
- 当前释义来自离线词库和人工短语覆盖，不依赖外部翻译服务。

### 3.4 语法

- 按词性和句法类别组织练习；
- 选择、填空等题型即时反馈；
- 保存进度和最后结果；
- 错题集中保存，可复习和重新作答。

### 3.5 听力

- 专项练习按 Part 和套题选择；
- 播放器支持播放、暂停、拖动进度、音量和 0.75×/1×/1.25×；
- 播放区域可随页面固定，滚动做题时仍可控制；
- 支持图片选择、选择题、填空和人物—选项匹配等模板；
- Part 5 使用左侧人物、右侧选项的匹配模板，允许改选；
- 模考按 Part 1–5 顺序，共 25 题，完成后统一评分；
- 计时从 00:00 开始，可暂停和继续；
- 结果页显示总分和各 Part 得分，支持看错题和只重做错题。

### 3.6 阅读与写作

- 阅读按正式 Part 组织，题目内容可使用 notice、email、message、article 等不同视觉模板；
- 阅读模考有统一顶部导航、计时、进度和完成页；
- 完成后显示总分、各 Part 得分、答案回顾和只重做错题；
- 阅读与写作被视为同一张试卷，KET 合计 60 分钟；
- 写作提供题目、字数要求、草稿保存、参考答案和提示；
- 参考答案必须与当前题目逐项对应。

### 3.7 口语

- 展示图片材料和逐题问题；
- 每一道问题使用对应的参考回答，不再用一段回答覆盖多题；
- Yes/No 问题的参考结构为“直接回答 + 理由 + 例子/细节”；
- 当前采用学习者自评，不声称为官方自动评分。

### 3.8 整套模考

- 一套题按“听力、阅读与写作、口语”组织；
- 每个 Paper 内再按 Part 顺序完成；
- 提供计时、暂停、刷新恢复、进度、交卷、分项得分、错题回顾和只重做错题；
- 专项训练和模考应读取同一题库数据，避免答案或版式分叉。

## 4. KET 题库现状

当前真题中心展示两个系列，共 20 套入口：

| 系列 | 数量 | 当前状态 |
| --- | ---: | --- |
| KET for Schools 青少版 | 12 套 | 完成度较高，已形成整套交互框架 |
| A2 Key 标准版 | 8 套 | 阅读写作可练；听力和口语仍需核对/补录 |

因此不得在对外文案中写“20 套完整真题全部完成”，除非逐套通过本文档和 `PET_FCE_DELIVERY_STANDARD.md` 的完整验收。

## 5. 当前技术实现

- 前端：React、Vite、React Router、Tailwind CSS、Framer Motion；
- 题库：JavaScript 静态结构化数据；
- 媒体：`public/audio` 和 `public/images`；
- 进度：浏览器 `localStorage`；
- 查词：离线词义表、词形还原和人工短语覆盖；
- 质量审计：阅读数据审计、全站词义覆盖审计、ESLint 和生产构建。

仓库约 3GB，`public` 约 886MB，其中音频约 855MB。正式上线时不能继续把所有媒体简单塞进前端仓库和单个构建包，应迁移到有版本管理、CDN 和访问日志的对象存储。

## 6. 尚未具备的生产能力

以下不是小修补，而是中国正式上线前必须建设的第二阶段：

- 学生/家长/教研账号与权限；
- 服务端数据库和跨设备同步；
- 账号注销、数据导出和删除；
- 教研题库后台、审核流和版本发布；
- 支付、订单、订阅和退款（如果收费）；
- 运营分析、学习报表和错误监控；
- 后端接口、防滥用、限流和审计日志；
- 对象存储、CDN、备份与恢复；
- 隐私政策、用户协议、未成年人保护机制；
- 版权和商标授权；
- 中国大陆域名、备案、合规评估和生产运维。

## 7. 产品成功标准

短期成功标准：

- KET 基准稳定，无阻断性题目、答案、音频或导航错误；
- PET/FCE 按同一交互标准完成，而不是另做两套互不兼容的网站；
- 所有题库来源可追溯，专项与模考使用同一数据；
- 用户能从错误回到学习，而不是只看到一个分数。

正式上线成功标准：

- 用户换设备仍能继续学习；
- 数据可恢复、可审计、可删除；
- 关键页面和音频在中国大陆网络环境下稳定；
- 题库内容拥有可证明的使用权；
- 所有合规、客服和运维责任有明确负责人。
